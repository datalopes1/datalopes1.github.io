# Portfólio de André Lopes

Site estático em português, com foco em oportunidades de Analista de BI e Analista de Dados Júnior. HTML e CSS sem etapa de build ou dependências de execução.

## Prévia local

Na raiz do repositório, execute `python -m http.server 8000` e abra http://localhost:8000.

## Conteúdo e fontes

- Experiências, formação e certificações: PDF do LinkedIn fornecido pelo titular na conversa de origem, consultado em 18/10/2026. Resumos fiéis, sem acrescentar ferramentas a experiências.
- Coffee Shop Sales: https://github.com/datalopes1/coffee/blob/main/README.md
- Telecom Churn: https://github.com/datalopes1/telecom_churn/blob/main/README.md
- Mercado imobiliário: https://github.com/datalopes1/pricing_imoveis/blob/main/README.md
- Contato: e-mail público documentado nos repositórios. O PDF pessoal não é distribuído neste site.

Os projetos são apresentados como estudos de portfólio, sem alegações de implantação em empresas ou resultados comerciais. A experiência na Democrata está indicada como atual conforme o PDF fornecido. Atualize esse status quando necessário.
